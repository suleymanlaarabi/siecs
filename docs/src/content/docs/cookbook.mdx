## Minimal world

```c
ecs_init();
ecs_entity_t e = ecs_new();
ecs_fini();
```

## Create a moving entity

```c
ecs_entity_t e = ecs_new();
ecs_set(e, Position, {0, 0});
ecs_set(e, Velocity, {1, 0});
```

## Iterate Position + Velocity

```c
ecs_query_id_t q = ecs_query({
    .components = {
        ecs_inout(Position),
        ecs_in(Velocity),
    },
});

ecs_iter_t it = ecs_query_iter(q);
while (ecs_iter_next(&it)) {
    Position *p = ecs_field(&it, 0);
    const Velocity *v = ecs_field(&it, 1);

    for (uint32_t i = 0; i < it.count; i++) {
        p[i].x += v[i].x;
        p[i].y += v[i].y;
    }
}

ecs_query_fini(q);
```

## Optional component

```c
ecs_query_id_t q = ecs_query({
    .components = {
        ecs_inout(Position),
        ecs_in_optional(Velocity),
    },
});
```

The optional field is `NULL` for a batch whose table lacks the component.

## Exclude a tag

```c
.components = {
    ecs_in(Position),
    ecs_not(Frozen),
}
```

## Parent and child

```c
ecs_entity_t parent = ecs_new();
ecs_entity_t child = ecs_new();

ecs_relate(child, ChildOf, parent);
```

## Query one relation target

For a `ByTarget` relation:

```c
.relations = {
    ecs_to(GroupOf, group),
}
```

## Shared inherited configuration

Register a component with shared inheritance, set it on an abstract base, then
create instances with `ecs_is_a()`.

Read-only queries can receive the base value as `EcsFieldShared`.

## Override inherited data

```c
ecs_set(instance, Material, local_material);
```

The instance now has local storage for that component.

## Defer structural mutation

```c
ecs_defer_begin();

ecs_add(e, Enemy);
ecs_remove(e, Sleeping);
ecs_relate(e, ChildOf, parent);

ecs_defer_end();
```

## Disable an entity

```c
ecs_add(e, Disabled);
```

Enable it:

```c
ecs_remove(e, Disabled);
```

## System with resource dependency

```c
ecs_system({
    .name = "Move",
    .phase = EcsOnUpdate,
    .query = {
        .components = {
            ecs_inout(Position),
            ecs_in(Velocity),
        },
        .resources = {
            { .id = ecs_id(Time), .access = EcsIn },
        },
    },
    .callback = Move,
});
```

## Run every half second

```c
ecs_system({
    .name = "Spawner",
    .phase = EcsOnUpdate,
    .interval = 0.5,
    .callback = Spawn,
});
```

## React to a set

```c
ecs_observer({
    .on = EcsOnSet,
    .query.components = { ecs_in(Position) },
    .callback = OnPositionSet,
});
```

## Custom event

```c
ecs_event_t Hit = ecs_event();

ecs_observer({
    .on = Hit,
    .callback = OnHit,
});

HitPayload payload = { .damage = 10 };
ecs_observer_trigger(target, Hit, &payload);
```

## Save and reload scene

```c
ecs_save("level.siecs");
ecs_load("level.siecs");
```

## Query disabled entities

```c
ecs_query_id_t q = ecs_query({
    .components = {
        ecs_in(Position),
        ecs_filter(Disabled),
    },
});
```

Mentioning `Disabled` explicitly allows that population to match.

## Query descendants of a base

```c
ecs_query_id_t q = ecs_query({
    .components = {
        ecs_in(Health),
    },
    .is_a = enemy_base,
});
```

## Read an ancestor component

For an acyclic ByTarget hierarchy relation:

```c
.components = {
    ecs_in(LocalTransform),
    ecs_up(WorldSettings, ChildOf),
}
```

## Order by hierarchy depth

```c
.order_by = ecs_order_by_depth(ChildOf)
```

Use when parents/lower depths must be processed before descendants.

## Main-thread render system

```c
ecs_system({
    .name = "Render",
    .phase = EcsOnRender,
    .main_thread_only = true,
    .callback = Render,
});
```

## Explicit system dependency

```c
ecs_system_id_t build = ecs_system({
    .name = "Build",
    .phase = EcsPostUpdate,
    .callback = Build,
});

ecs_system({
    .name = "Consume",
    .phase = EcsPostUpdate,
    .after = { build },
    .callback = Consume,
});
```

## No-defer task

Use only for a task without entity query iteration:

```c
ecs_system({
    .name = "ImmediateTask",
    .phase = EcsPostUpdate,
    .no_defer = true,
    .callback = ImmediateTask,
});
```

## Monotonic entity allocation

```c
ecs_entity_t tool_entity = ecs_new_no_reuse();
```

Use when runtime numeric allocation order is needed; do not treat the index as a
persistent cross-session id.

## Validate a scene before loading

```c
if (ecs_scene_validate(data, size)) {
    ecs_load_memory(data, size);
}
```
