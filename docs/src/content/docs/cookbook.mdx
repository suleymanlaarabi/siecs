## Iterate Position + Velocity

<Tabs syncKey="language">
<TabItem label="C">

```c
ecs_query_id_t q = ecs_query({
    .components = {
        ecs_inout(Position),
        ecs_in(Velocity),
    },
});

ecs_iter_t it = ecs_query_iter(q);
while (ecs_iter_next(&it)) {
    Position *p = ecs_field(&it, 0);
    const Velocity *v = ecs_field(&it, 1);

    for (uint32_t i = 0; i < it.count; i++) {
        p[i].x += v[i].x;
        p[i].y += v[i].y;
    }
}

ecs_query_fini(q);
```

</TabItem>
<TabItem label="C++">

```cpp
auto q = ecs::query().build_handle();
q.each([](Position &p, const Velocity &v) {
    p.x += v.x;
    p.y += v.y;
});
```

</TabItem>
</Tabs>

## Optional component

<Tabs syncKey="language">
<TabItem label="C">

```c
ecs_query_id_t q = ecs_query({
    .components = {
        ecs_inout(Position),
        ecs_in_optional(Velocity),
    },
});
```

</TabItem>
<TabItem label="C++">

```cpp
ecs::query().each([](Position &p, ecs::optional<const Velocity> v) {
    if (v) {
        p.x += v->x;
    }
});
```

</TabItem>
</Tabs>

The optional field is `NULL` for a batch whose table lacks the component.

## Shared inherited configuration

Register a component with shared inheritance, set it on an abstract base, then
create instances with `ecs_is_a()`.

Read-only queries can receive the base value as `EcsFieldShared`.

## Defer structural mutation

<Tabs syncKey="language">
<TabItem label="C">

```c
ecs_defer_begin();

ecs_add(e, Enemy);
ecs_remove(e, Sleeping);
ecs_relate(e, ChildOf, parent);

ecs_defer_end();
```

</TabItem>
<TabItem label="C++">

```cpp
// In a typed system callback, SIECS defers structural changes automatically.
ecs::system("Wake")
    .each([parent](ecs::entity entity) {
        entity.add<Enemy>().remove<Sleeping>().child_of(parent);
    });
```

</TabItem>
</Tabs>

## System with resource dependency

<Tabs syncKey="language">
<TabItem label="C">

```c
ecs_system({
    .name = "Move",
    .phase = EcsOnUpdate,
    .query = {
        .components = {
            ecs_inout(Position),
            ecs_in(Velocity),
        },
        .resources = {
            { .id = ecs_id(Time), .access = EcsIn },
        },
    },
    .callback = Move,
});
```

</TabItem>
<TabItem label="C++">

```cpp
ecs::system("Move")
    .phase(EcsOnUpdate)
    .each([](Position &p, const Velocity &v, ecs::res<const Time> time) {
        p.x += v.x * time->dt;
        p.y += v.y * time->dt;
    });
```

</TabItem>
</Tabs>

## Custom event

<Tabs syncKey="language">
<TabItem label="C">

```c
ecs_event_t Hit = ecs_event();

ecs_observer({
    .on = Hit,
    .callback = OnHit,
});

HitPayload payload = { .damage = 10 };
ecs_observer_trigger(target, Hit, &payload);
```

</TabItem>
<TabItem label="C++">

```cpp
struct Hit {};

ecs::observe<Hit>()
    .each([](ecs::observer_event event) {
        const HitPayload *payload = event.trigger_data<HitPayload>();
        (void)payload;
    });

HitPayload payload{ .damage = 10 };
ecs::trigger<Hit>(target, &payload);
```

</TabItem>
</Tabs>

    .no_defer = true,

</TabItem>
<TabItem label="C++">

## Validate a scene before loading

<Tabs syncKey="language">
<TabItem label="C">

```c
if (ecs_scene_validate(data, size)) {
    ecs_load_memory(data, size);
}
```

</TabItem>
<TabItem label="C++">

```cpp
if (!ecs_scene_validate(data, size)) {
    throw std::runtime_error("invalid scene data");
}
if (!ecs_load_memory(data, size)) {
    throw std::runtime_error("scene loading failed");
}
```

</TabItem>
