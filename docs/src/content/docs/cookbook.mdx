## Game Loop With Time

<Tabs syncKey="language">
<TabItem label="C">
```c
ECS_RESOURCE(Time, { float dt; });
ECS_COMPONENT(Position, { float x; });
ECS_COMPONENT(Velocity, { float x; });

static void Move(ecs_iter_t *it) {
    const Time *time = ecs_get_resource_read(it->world, Time);
    Position *p = ecs_field(it, 0);
    const Velocity *v = ecs_field(it, 1);
    for (uint32_t i = 0; i < it->count; i++) p[i].x += v[i].x * time->dt;
}
```
</TabItem>
<TabItem label="C++">
```cpp
struct Time { float dt; };
struct Position { float x; };
struct Velocity { float x; };

ecs::set_resource(Time{ .dt = 0.016f });
ecs::system("Move").each([](ecs::res<const Time> time,
                              Position &p, const Velocity &v) {
    p.x += v.x * time->dt;
});
```
</TabItem>
</Tabs>

## Parent And Child

<Tabs syncKey="language">
<TabItem label="C">
```c
ecs_entity_t parent = ecs_new();
ecs_entity_t child = ecs_new();
ecs_set(child, ChildOf, { parent });
```
</TabItem>
<TabItem label="C++">
```cpp
auto parent = ecs::entity::create();
auto child = ecs::entity::create().child_of(parent);
```
</TabItem>
</Tabs>

`ChildOf` cascades deletion: killing the parent also kills its children.

## Optional Component Query

<Tabs syncKey="language">
<TabItem label="C">
```c
ecs_query_id_t q = ecs_query({
    .terms = { ecs_inout(Position), ecs_in_optional(Velocity) },
});
```
</TabItem>
<TabItem label="C++">
```cpp
auto query = ecs::query()
    .require<Position>()
    .each([](Position &position) {
        // Query optional data through the C API when needed.
        (void)position;
    });
```
</TabItem>
</Tabs>

## React To A Component Set

<Tabs syncKey="language">
<TabItem label="C">
```c
static void OnPositionSet(ecs_observer_event_t *event) {
    const Position *incoming = event->trigger_data;
    (void)incoming;
}

ecs_observer({
    .on = EcsOnSet,
    .query.terms = { ecs_in(Position) },
    .callback = OnPositionSet,
});
```
</TabItem>
<TabItem label="C++">
```cpp
ecs::observe<ecs::OnSet>().each([](const Position &position) {
    std::cout << position.x << '\n';
});
```
</TabItem>
</Tabs>

## Pause Entities With Disabled

<Tabs syncKey="language">
<TabItem label="C">
```c
ecs_add(entity, Disabled);
ecs_remove(entity, Disabled);
```
</TabItem>
<TabItem label="C++">
```cpp
entity.disable();
entity.enable();
```
</TabItem>
</Tabs>

Normal queries skip disabled entities. Add `ecs_filter(Disabled)` to match them
explicitly.
