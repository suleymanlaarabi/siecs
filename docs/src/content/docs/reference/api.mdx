This page is a compact API map. The manuals explain behavior, invariants and
performance tradeoffs.

## World lifecycle

| Purpose | C | C++ |
| --- | --- | --- |
| Initialize | `ecs_init()` | `ecs::init()` |
| Initialize with features | `ecs_init_w_features()` | `ecs::init(features)` |
| Progress scheduler | `ecs_progress()` | `ecs::progress()` |
| Run all systems | `ecs_run()` | wrapper/public C interop |
| Run one phase | `ecs_run_phase()` | `ecs::run_phase()` |
| Run one system | `ecs_run_system()` | `ecs::run_system()` |
| Request quit | `ecs_quit()` | `ecs::quit()` |
| Finalize | `ecs_fini()` | `ecs::fini()` |

`ecs_world_feat_desc_t` includes target FPS and worker-thread configuration.

## Entities

| Purpose | C | C++ |
| --- | --- | --- |
| Create | `ecs_new()` | `ecs::entity::create()` |
| Create without reuse | `ecs_new_no_reuse()` | `create_no_reuse()` |
| Test alive | `ecs_is_alive()` | `entity::is_alive()` |
| Resolve current handle by index | `ecs_entity_from_index()` | C interop |
| Name | `ecs_entity_name()` | entity name helpers |
| Lookup | `ecs_lookup()` | `entity::lookup()` |
| Kill | `ecs_kill()` | `entity::kill()` |
| Mark abstract | `ecs_abstract()` | `entity::abstract()` |
| Get base | `ecs_entity_base()` | entity inheritance helpers |
| Test IsA | `ecs_is()` | typed/entity wrapper |

Entity handle helpers:

```c
ecs_entity_id(entity)
ecs_entity_generation(entity)
```

## Component metadata

`ecs_component_info(component)` exposes immutable registered metadata such as:

- name;
- size;
- reflection handle/descriptor;
- inheritance policy;
- debug mutation metadata where enabled.

Use this for tools/introspection rather than reading internal component indexes.

## Relation metadata

`ecs_relation_info(relation)` exposes:

- registered name;
- storage mode;
- target deletion policy;
- acyclic flag.

Generic relation tools should branch on this metadata before offering
target/depth traversal operations.
